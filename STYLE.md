# STYLE.md

## Purpose

This file defines the visual style for the "مُدرّس" tutoring marketplace.

The UI must follow the attached design direction:
- Arabic-first
- RTL-first
- Premium education marketplace
- Calm, trustworthy, and professional

---

## Brand Feel

The product should feel:
- Premium
- Educational
- Trustworthy
- Qatari/local
- Simple for parents and students
- Professional for tutors

Avoid:
- Childish visuals
- Overly colorful UI
- Generic SaaS blue styling
- Western LTR layouts
- Heavy animations

---

## Colors

Primary colors:
- Dark red
- Gold
- Cream background

Usage:
- Dark red for primary actions, headings, key highlights
- Gold for accents, badges, subtle highlights
- Cream for page background
- White for cards and forms
- Neutral gray for secondary text

Do not introduce a new dominant brand color.

---

## Typography

Fonts:
- Cairo
- Tajawal

Rules:
- Arabic readability is the top priority.
- Headings should feel premium and confident.
- Body text should be clean and readable.
- Do not use tiny text sizes on mobile.

---

## Layout

Rules:
- RTL layout everywhere
- Mobile-first responsive design
- Clear spacing between sections
- Cards should feel calm and premium
- Avoid cramped dashboards
- Use consistent padding across pages

---

## Buttons

Primary button:
- Dark red background
- White text
- Rounded corners
- Clear hover state

Secondary button:
- White or cream background
- Dark red text
- Border in dark red or neutral color

Danger button:
- Used only for destructive actions

---

## Cards

Tutor cards:
- White background
- Soft shadow
- Rounded corners
- Clear tutor image
- Name, rating, subjects, price, and teaching mode visible
- Primary CTA visible

Dashboard cards:
- Clean
- Data-focused
- No excessive decoration

---

## Forms

Forms must be:
- RTL
- Clearly labeled
- Easy on mobile
- With helpful validation messages
- Not visually crowded

Required states:
- Default
- Focus
- Error
- Disabled
- Loading

---

## Tables

Admin tables:
- Simple
- Readable
- With clear actions
- Mobile fallback as cards when needed

---

## Calendar UI

Tutor availability calendar:
- Weekly grid
- Days as columns
- Time as rows
- Similar to calendar layout
- Slots should be visually clear
- Different teaching modes must be visually distinguishable:
  - Online
  - In-person
  - Both

---

## Responsive Rules

Mobile:
- Single column
- Sticky important CTAs when useful
- Large tap targets

Tablet:
- Two-column layouts where appropriate

Desktop:
- Wider dashboards
- Sidebar allowed for authenticated dashboards

---

## Animation

Use minimal animation only:
- Hover transitions
- Button feedback
- Modal fade
- Loading skeleton

Do not use heavy motion.
