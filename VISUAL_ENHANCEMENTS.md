# VISUAL_ENHANCEMENTS.md

## Purpose

This file defines optional visual enhancements for the "مُدرّس" platform.

These enhancements should improve perceived quality without changing the core design system.

---

## Core Rule

Visual enhancements are supporting elements only.

They must not override:
- STYLE.md
- UI_RULES.md
- SITE_STRUCTURE.md
- SYSTEM_FLOW.md

---

## Design Reference Usage

Refero may be used only for:
- interaction inspiration
- layout inspiration
- dashboard patterns
- calendar UI ideas
- marketplace card ideas
- onboarding flows
- AI report visualization ideas

Google Stitch may be used for:
- visual enhancement ideas
- motion ideas
- empty state ideas
- AI card visuals
- dashboard polish

Do not copy full products directly.

All final implementation must follow:
- STYLE.md
- UI_RULES.md
- COMPONENT_LIBRARY.md
- VISUAL_ENHANCEMENTS.md

If external references conflict with project files, project files always win.

Maintain one consistent visual language across the entire product.

---

## Allowed Enhancements

### Hero Enhancements

Allowed:
- subtle educational illustration
- soft abstract shapes
- gentle background gradients
- premium card preview
- small animated accent

Avoid:
- heavy video background
- distracting motion
- overly playful visuals

---

### Tutor Card Enhancements

Allowed:
- soft hover lift
- subtle border highlight
- rating emphasis
- availability indicator
- teaching mode chips

Avoid:
- excessive shadows
- animated card flipping
- distracting badges

---

### AI Report Enhancements

Allowed:
- progress rings
- strength/weakness chips
- recommendation cards
- light chart visualization
- report completion animation

AI report visuals should feel:
- educational
- clear
- parent-friendly
- calm

---

### Calendar Enhancements

Allowed:
- hover state on slots
- selected slot highlight
- smooth drag feedback
- online/in-person color indicators
- subtle disabled slot treatment

Avoid:
- complex motion
- confusing colors
- heavy calendar libraries unless necessary

---

### Dashboard Enhancements

Allowed:
- stat card micro animation
- soft counters
- calm badges
- progress indicators
- lightweight empty state illustrations

Avoid:
- gamified excessive animations
- financial dashboard complexity
- too many colors

---

### Empty State Enhancements

Use illustrations for:
- no bookings
- no messages
- no reports
- no tutors found
- no withdrawals

Illustration style:
- soft
- educational
- simple
- Arabic-friendly
- not childish

---

## Forbidden Enhancements

Do not add:
- autoplay audio
- flashing elements
- heavy particles
- full-screen intro animation
- complex 3D scenes
- parallax-heavy pages
- unnecessary background videos

---

## Performance Rule

Every enhancement must be lightweight.

If an enhancement slows mobile performance, remove it.

---

## Accessibility Rule

Visual effects must not reduce:
- readability
- contrast
- clarity
- usability
